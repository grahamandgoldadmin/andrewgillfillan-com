# andrewgillfillan.com

Static portfolio website for Andrew Gillfillan.

## Deployment

- No build command is required.
- Publish the repository root as the site directory.
- The production domain is `andrewgillfillan.com`.
- The domain may remain registered and managed at GoDaddy while DNS points to the hosting provider.

## Source

The production files were prepared from the original Claude export, `Portfolio website project.zip`. The original archive is preserved outside this repository. Duplicate uploads, design contact sheets, and assets unused by the live pages are intentionally excluded.
